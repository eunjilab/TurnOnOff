# CEO 제안서 톤 수정 계획서

## 수정 배경
- **현재 상황**: 이번 달까지 회사 근무, 이후 개인 진행 가능
- **발표 목적**: 다음 주 설명 (계획 공유/정리 목적)
- **기존 톤**: "제안/허락 구하는" 느낌 → 수동적
- **변경 톤**: "계획 공유" 느낌 → 자신감 있게

---

## 수정 항목 상세

### 1. 제목 변경 (2곳)

#### 1-1. HTML title 태그 (Line 6)
```html
<!-- 현재 -->
<title>다음 단계 제안서</title>

<!-- 변경 -->
<title>다음 단계 계획</title>
```

#### 1-2. 메인 타이틀 (Line 948)
```html
<!-- 현재 -->
<h1>다음 단계에 대한<br>제안서</h1>

<!-- 변경 -->
<h1>다음 단계에 대한<br>계획</h1>
```

---

### 2. 섹션 제목 변경 (Line 1276)

```html
<!-- 현재 -->
<h2>목표 및 제안</h2>

<!-- 변경 -->
<h2>목표 및 계획</h2>
```

**서브타이틀도 변경 (Line 1277)**
```html
<!-- 현재 -->

```

---

### 3. 허락 구하는 표현 삭제 (2곳)

#### 3-1. 06번 슬라이드 - 기존 계정 사용 (Line 1409~1413)

```html
<!-- 현재 -->
<h3 style="margin-top: 24px;">기존 계정 사용</h3>
<p>
  기존에 사용하던 뷰타민 계정의 구글과 네이버 계정은<br>
  제가 업무를 짜놓은 것이 많아서, 계속 사용해도 괜찮을지 요청드립니다.
</p>

<!-- 변경 -->
<h3 style="margin-top: 24px;">기존 계정 활용 계획</h3>
<p>
  기존에 사용하던 뷰타민 계정의 구글과 네이버 계정에<br>
  업무 자동화 설정이 되어 있어서 그대로 활용할 예정입니다.
</p>
```
**변경 포인트**: "~괜찮을지 요청드립니다" 삭제 → 활용 계획으로 변경

---

#### 3-2. 07번 슬라이드 - 요청사항 (Line 1438~1443)

```html
<!-- 현재 -->
<div style="text-align: left; margin: 32px auto 0;">
  <p style="font-size: 14px; color: #888; margin-bottom: 12px;">요청 사항:</p>
  <p style="font-size: 15px; line-height: 2.2; color: #5a5a5a;">
    ✓ 기존 구글/네이버 계정 - 계속 사용해도 괜찮을지 요청드립니다<br>
    ✓ 회사 업무 병행 가능
  </p>
</div>

<!-- 변경 -->
<div style="text-align: left; margin: 32px auto 0;">
  <p style="font-size: 14px; color: #888; margin-bottom: 12px;">참고 사항:</p>
  <p style="font-size: 15px; line-height: 2.2; color: #5a5a5a;">
    ✓ 기존 구글/네이버 계정 활용 예정<br>
    ✓ 회사 업무 병행 가능
  </p>
</div>
```
**변경 포인트**:
- "요청 사항" → "참고 사항"
- "~괜찮을지 요청드립니다" → "활용 예정"

---

### 4. 클로징 멘트 변경 (Line 1453~1455)

```html
<!-- 현재 -->
<p style="font-size: 18px; color: #5a5a5a; line-height: 2; text-align: center;">
  함께 해주시면,<br>좋은 결과로 보답하겠습니다.
</p>

<!-- 변경 -->
<p style="font-size: 18px; color: #5a5a5a; line-height: 2; text-align: center;">
  좋은 결과를 만들어가겠습니다.
</p>
```
**변경 포인트**: "함께 해주시면" (협조 요청) 삭제 → 의지 표현으로

## 수정 원칙
1. "~해도 될까요?", "~요청드립니다" 등 **허락 구하는 표현 삭제**
2. 설명이 필요한 부분은 유지하되, **자신감 있는 어투**로 변경
3. "제안" → "계획"으로 **일관성** 있게 변경
4. 클로징은 협조 요청보다 **의지 표현**으로 변경
