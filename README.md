# 👗 Turn ON/OFF

> 세트로 사면 코디 고민 끝. ON인지 OFF인지만 고르면 된다.

## 🎯 프로젝트 개요

| 항목 | 내용 |
|-----|-----|
| **브랜드명** | Turn ON/OFF |
| **컨셉** | TPO 기반 세트 판매 (ON=외출룩, OFF=편한룩) |
| **타겟** | 20-30대 여성 |
| **스타일** | 러블리, 파스텔, 편한 핏 |
| **가격대** | 세트 5~12만원 |
